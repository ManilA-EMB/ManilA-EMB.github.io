# Портфоліо комп'ютерної вишивки

Статичний GitHub Pages сайт без фреймворків.

## Файли
- `index.html` — сайт
- `assets/images/logo.png` — логотип
- `assets/images/work-01.jpg` тощо — фото робіт

Для нової роботи скопіюй `<article class="work">...</article>` у `index.html` і зміни дані та назву фото.
